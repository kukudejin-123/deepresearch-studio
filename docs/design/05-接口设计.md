# 05 接口设计

## 5.1 REST API 总览

Base URL：`http://localhost:8000`（容器部署时经 Nginx 同源反代）

认证方式：除注册/登录外，所有接口需要 `Authorization: Bearer <token>` 请求头。

### 5.1.1 接口清单

| 方法 | 路径 | 认证 | 说明 |
| --- | --- | --- | --- |
| POST | /api/auth/register | 否 | 注册并返回 JWT |
| POST | /api/auth/login | 否（限流） | 登录并返回 JWT |
| GET | /api/auth/me | 是 | 查询当前用户 |
| POST | /api/task | 是（限流+并发） | 提交任务 |
| POST | /api/task/{thread_id}/cancel | 是 | 取消任务 |
| GET | /api/tasks | 是 | 任务列表（本人） |
| GET | /api/task/{thread_id} | 是 | 任务详情（本人） |
| GET | /api/task/{thread_id}/events | 是 | 事件回放（本人） |
| POST | /api/upload | 是 | 上传文件（本人会话） |
| GET | /api/files | 是 | 文件列表（本人目录） |
| GET | /api/download | 是（token 可走 query） | 下载文件 |
| GET | /api/health | 否 | 健康检查 |
| GET | /metrics | 否 | Prometheus 指标 |
| WS | /ws/{thread_id} | 是（token 走 query） | 实时事件推送 |

## 5.2 认证接口

### 5.2.1 注册

**请求**：

```http
POST /api/auth/register
Content-Type: application/json

{"username": "alice", "password": "secret123"}
```

**响应**（201）：

```json
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": {"id": 1, "username": "alice"}
}
```

**错误**：

| 状态码 | 场景 | detail |
| --- | --- | --- |
| 400 | 用户名/密码格式不合法 | "用户名长度需在 3-32 个字符之间" |
| 409 | 用户名已存在 | "用户名已被注册" |

### 5.2.2 登录

**请求**：

```http
POST /api/auth/login
Content-Type: application/json

{"username": "alice", "password": "secret123"}
```

**响应**（200）：同注册。

**错误**：

| 状态码 | 场景 | detail |
| --- | --- | --- |
| 401 | 用户名或密码错误 | "用户名或密码错误"（不区分两种） |
| 429 | 频繁失败 | "登录尝试过于频繁，请 N 秒后重试" |

### 5.2.3 当前用户

**请求**：`GET /api/auth/me` + Authorization 头

**响应**（200）：`{"user": {"id": 1, "username": "alice"}}`

**错误**：401（未登录/token 无效/用户不存在）

## 5.3 任务接口

### 5.3.1 提交任务

**请求**：

```http
POST /api/task
Authorization: Bearer <token>
Content-Type: application/json

{"query": "查询阿莫西林的库存", "thread_id": "可选，不传则服务端生成"}
```

**响应**（200）：

```json
{"status": "started", "thread_id": "uuid", "queue": "memory"}
```

**错误**：

| 状态码 | 场景 | detail |
| --- | --- | --- |
| 401 | 未登录 | "未登录或登录已过期" |
| 429 | 频率超限 | "任务提交过于频繁，请 N 秒后重试" |
| 429 | 并发超限 | "同时进行的任务数已达上限（2）" |
| 503 | 队列不可用（arq 模式 Redis 故障） | "任务队列暂不可用: ..." |

**设计说明**：thread_id 由客户端预生成并先建 WebSocket，再提交任务——保证事件不丢失（先订阅后执行）。

### 5.3.2 取消任务

**请求**：`POST /api/task/{thread_id}/cancel`

**响应**（200）：

```json
{"status": "cancelled", "thread_id": "uuid"}
// 或
{"status": "cancelling", "thread_id": "uuid"}  // 运行中任务，协作式取消
```

**错误**：401（未登录）、404（任务不存在/不属于本人/已结束）

### 5.3.3 任务列表与详情

**请求**：`GET /api/tasks?limit=50`

**响应**：

```json
{
  "tasks": [
    {
      "thread_id": "uuid",
      "user_id": 1,
      "query": "查询库存",
      "status": "completed",
      "error": null,
      "created_at": "2026-10-15 10:00:00",
      "updated_at": "2026-10-15 10:02:30"
    }
  ]
}
```

### 5.3.4 事件回放

**请求**：`GET /api/task/{thread_id}/events?after_seq=0`

**响应**：

```json
{
  "events": [
    {
      "seq": 1,
      "event": "session_created",
      "message": "工作目录已创建: ...",
      "data": {"path": "..."},
      "timestamp": "2026-10-15 10:00:01"
    }
  ],
  "last_seq": 5
}
```

**使用方式**：前端记录已收到的最大 seq，重连后传 `after_seq={max}` 拉取缺口。

## 5.4 文件接口

### 5.4.1 上传

**请求**：

```http
POST /api/upload
Authorization: Bearer <token>
Content-Type: multipart/form-data

files: <binary>
thread_id: uuid
```

**响应**（200）：`{"status": "uploaded", "files": ["报告.pdf"]}`

**错误**：

| 状态码 | 场景 | detail |
| --- | --- | --- |
| 400 | 类型不允许 | "不支持的文件类型 .exe，允许的类型: ..." |
| 400 | 文件名不合法 | "文件名不合法: ..." |
| 400 | 文件数超限 | "单次最多上传 10 个文件" |
| 413 | 大小超限 | "文件 xxx 超过大小上限 20MB" |

### 5.4.2 文件列表

**请求**：`GET /api/files?path=/abs/path/to/session/dir`

**响应**：

```json
{
  "files": [
    {"name": "报告.md", "type": "file", "path": "/abs/...", "size": 2048, "mtime": 1729000000}
  ]
}
```

**错误**：403（路径越权）、404（目录不存在）

### 5.4.3 下载

**请求**：`GET /api/download?path=/abs/path&token=<jwt>`（或 Authorization 头）

**响应**：文件二进制流（FileResponse）

**错误**：401（未认证）、403（路径越权）、404（文件不存在）

## 5.5 WebSocket 协议

### 5.5.1 连接

```
ws://localhost:8000/ws/{thread_id}?token=<jwt>
```

### 5.5.2 消息格式（服务端 → 客户端）

**监控事件**：

```json
{
  "type": "monitor_event",
  "event": "tool_start",
  "message": "开始执行工具: 网络搜索工具",
  "data": {"tool_name": "网络搜索工具", "args": {...}},
  "timestamp": "2026-10-15T10:00:01.123456",
  "seq": 3
}
```

**事件类型**：

| event | 触发时机 | data 内容 |
| --- | --- | --- |
| session_created | 任务开始，工作目录创建 | {"path": "..."} |
| assistant_call | 主智能体调度子智能体 | {"assistant_name": "...", "args": {...}} |
| tool_start | 工具被调用 | {"tool_name": "...", "args": {...}} |
| task_result | 模型产出最终结果 | {"result": "..."} |
| task_cancelled | 任务被取消 | {} |
| error | 执行异常 | {}（message 含错误详情） |

**心跳**：

```json
{"type": "pong", "message": "服务端已收到: ping"}
```

### 5.5.3 消息格式（客户端 → 服务端）

纯文本 `"ping"`（心跳，25 秒间隔）。

### 5.5.4 断线重连策略（前端）

1. `onclose` 触发 → 2 秒后重连；
2. 重连成功 → 调 `/api/task/{id}/events?after_seq={lastSeq}` 回放缺口；
3. 实时事件按 seq 去重（`seq <= lastSeq` 的直接跳过）；
4. 新 thread（新建会话）时重置 lastSeq 为 0。

## 5.6 错误码规范

| 状态码 | 含义 | 使用场景 |
| --- | --- | --- |
| 200 | 成功 | 正常响应 |
| 201 | 创建成功 | 注册 |
| 400 | 请求错误 | 参数校验失败 |
| 401 | 未认证 | 无 token/token 无效 |
| 403 | 禁止访问 | 资源越权（文件路径） |
| 404 | 不存在 | 任务不存在/不属于本人 |
| 413 | 实体过大 | 上传文件超限 |
| 429 | 频率超限 | 限流/并发上限 |
| 500 | 服务端错误 | 未预期异常 |
| 503 | 服务不可用 | 队列故障 |

**错误响应体**：

```json
{"detail": "人类可读的错误说明"}
```

## 5.7 健康检查与指标

### 5.7.1 /api/health

```json
{"status": "ok", "task_store": "ok"}
```

检查进程存活与任务存储可读写，不触发 LLM/MySQL 等外部依赖（避免探活误判）。状态 degraded 时返回 503。

### 5.7.2 /metrics

Prometheus 文本格式，指标清单：

| 指标 | 类型 | 标签 |
| --- | --- | --- |
| deepresearch_tasks_total | Counter | status（submitted/completed/failed/cancelled） |
| deepresearch_tasks_active | Gauge | - |
| deepresearch_tool_calls_total | Counter | tool |
| deepresearch_http_requests_total | Counter | method/path/status |
| deepresearch_task_duration_seconds | Histogram | - |
