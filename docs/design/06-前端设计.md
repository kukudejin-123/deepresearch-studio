## 6.2 认证流程

### 6.2.1 认证门控

```tsx
export default function App() {
  const [user, setUser] = useState<AuthUser | null>(() =>
    getToken() ? getStoredUser() : null
  );

  if (!user) {
    return <AuthPanel onAuthenticated={setUser} />;
  }
  return <ResearchConsole user={user} onLogout={() => setUser(null)} />;
}
```

**设计要点**：未登录时不渲染研究台，也不建立 WebSocket 连接——避免无谓的连接与 401 噪音。

### 6.2.2 token 管理（lib/auth.ts）

```typescript
export function getToken(): string | null {
  return window.localStorage.getItem("deepresearch-studio.token");
}

export async function authFetch<T>(path: string, init?: RequestInit): Promise<T> {
  const headers = new Headers(init.headers);
  const token = getToken();
  if (token) headers.set("Authorization", `Bearer ${token}`);
  
  const response = await fetch(`${API_BASE_URL}${path}`, { ...init, headers });
  if (response.status === 401) {
    clearAuth();  // 自动清理并回到登录页
  }
  // ...错误处理
}
```

**401 自动处理**：任何接口返回 401（token 过期/被删用户）时清理本地态，下次渲染自动回到登录页。

### 6.2.3 登录/注册页（AuthPanel.tsx）

- Ant Design Tabs 切换登录/注册；
- 表单校验：用户名 3-32 字符（字母数字下划线连字符）、密码 6-72 字符；
- 注册成功直接登录（服务端注册接口即返回 token）；
- 错误提示通过 AntApp 的 message 统一展示。

## 6.3 会话状态管理

### 6.3.1 核心 Hook：useDeepAgentSession

所有会话状态集中在一个自定义 Hook 中：

```typescript
const {

  files,              // 产物文件列表
  isRunning,          // 任务执行中
  isCancelling,       // 取消中
  isUploading,        // 上传中
  lastError,          // 最近错误
  result,             // 最终结果
  sessionPath,        // 会话目录（用于文件列表）
  threadId,           // 当前会话 ID
  submitTask,         // 提交任务
  cancelCurrentTask,  // 取消任务
  uploadFiles,        // 上传文件
  resetSession,       // 新建会话
  refreshFiles,       // 刷新文件列表
} = useDeepAgentSession();
```

### 6.3.2 状态提升

App.tsx 中的 ResearchConsole 把 session 的 events/files/result 同步到 turns（对话轮次）：

```tsx
useEffect(() => {
  setTurns((previous) => {
    const latestTurn = previous[previous.length - 1];
    return [...previous.slice(0, -1), {
      ...latestTurn,
      events: session.events,
      files: session.files,
      isRunning: session.isRunning,
      result: session.result,
    }];
  });
}, [session.events, session.files, session.isRunning, session.result]);
```

多轮对话通过 turns 数组实现：每次提交任务 push 一个新 turn，事件流实时更新最后一个 turn。

## 6.4 WebSocket 与事件回放

### 6.4.1 连接管理

```typescript
function connect() {
  const token = getToken();
  const wsUrl = `${WS_BASE_URL}/ws/${encodeURIComponent(threadId)}${
    token ? `?token=${encodeURIComponent(token)}` : ""
  }`;
  const socket = new WebSocket(wsUrl);
  
  socket.onopen = () => {
    setConnectionState("connected");
    void replayMissedEvents();  // 连接后立即回放
    heartbeatTimerRef.current = setInterval(() => {
      if (socket.readyState === WebSocket.OPEN) socket.send("ping");
    }, 25000);
  };
  
  socket.onclose = () => {
    reconnectTimerRef.current = setTimeout(connect, 2000);  // 2 秒重连
  };
}
```

### 6.4.2 事件回放与去重（第二期新增）

```typescript
const lastSeqRef = useRef(0);

const replayMissedEvents = useCallback(async () => {
  const response = await fetchTaskEvents(threadId, lastSeqRef.current);
  const missed = response.events.filter((e) => e.seq > lastSeqRef.current);
  if (missed.length === 0) return;
  
  lastSeqRef.current = Math.max(...missed.map((e) => e.seq));
  setEvents((previous) => [...previous, ...missed.map(toMonitorMessage)].slice(-120));
}, [threadId]);

// 实时消息去重
socket.onmessage = (event) => {
  const payload = JSON.parse(event.data);
  if (typeof payload.seq === "number") {
    if (payload.seq <= lastSeqRef.current) return;  // 已回放过的跳过
    lastSeqRef.current = payload.seq;
  }
  setEvents((previous) => [...previous, payload].slice(-120));
};
```

**thread 切换处理**：新建会话时 lastThreadRef 变化 → 重置 lastSeqRef 为 0（从头开始）；同一 thread 重连时保留 lastSeqRef（只回放缺口）。

### 6.4.3 事件渲染

不同事件类型渲染不同样式：

- `assistant_call`：显示“正在调用哪个专家助手”（带助手图标）；
- `tool_start`：显示工具名和参数（折叠展示）；
- `task_result`：最终结果（Markdown 渲染）；
- `error`：红色错误提示；
- `session_created`：提取 path 设置 sessionPath（触发文件列表刷新）。

### 6.5.2 下载链接

```typescript
export function getDownloadUrl(path: string): string {
  const url = new URL(apiUrl("/api/download"));
  url.searchParams.set("path", path);
  const token = getToken();
  if (token) url.searchParams.set("token", token);  // 浏览器直链无法带请求头
```

## 6.6 部署配置

### 6.6.1 同源部署（容器）

```typescript
// config.ts
function resolveApiBaseUrl(): string {
  const configured = import.meta.env.VITE_API_BASE_URL;
  if (configured === undefined) return "http://localhost:8000";  // 本地开发
  return stripTrailingSlash(configured);  // 空串 = 同源
}

function deriveWsBaseUrl(apiBaseUrl: string): string {
  if (!apiBaseUrl) {
    // 同源：WebSocket 走当前页面协议与主机
    return `${window.location.protocol === "https:" ? "wss" : "ws"}://${window.location.host}`;
  }
  // ...分离部署推导
}
```

**三种模式**：

| 模式 | VITE_API_BASE_URL | 场景 |
| --- | --- | --- |
| 本地开发 | 不设置（默认 localhost:8000） | pnpm dev |
| 同源部署 | 空字符串 | Docker（Nginx 反代） |
| 分离部署 | 显式地址 | 前后端分开托管 |
